01 · AI Product Private · in development

BeBeyond

How does personalised fitness guidance become an intelligent product rather than another workout tracker?

An AI fitness and nutrition platform I designed and built end to end. A deterministic engine owns every number it reports, readiness, accumulated load and nutrition targets, and the language model is only allowed to explain that decision. It cannot invent a figure.

The intelligence

  • Exercise ontology modelling how movements and muscles relate
  • Readiness and accumulated muscle load, each signal carrying a confidence tier
  • Recommendation engine that carries the evidence behind its answer
  • Nutrition engine working off the same state as the training side

Current state

  • Built and tested: ontology, readiness, recommendations, nutrition, 3D exercise view
  • Simulated: camera form analysis runs on a scripted pose source, not live inference
  • Scaffolded: wearable adapters exist, no live data flows yet

03 · Machine Learning

Fraud Detection

Can a model catch the fraud a baseline misses, and explain itself well enough to be acted on?

Independent project on a public dataset. XGBoost against a logistic regression baseline, SMOTE for the heavy class imbalance, and SHAP so each flag can be traced to the features behind it.

99.9% AUC-ROC on a public dataset
97.2% precisionXGBoostSMOTESHAP

Public dataset, not proprietary card network data. It is cleaner and more separable than real transactions, so the ceiling is higher than production would allow. The useful part is explainability, not the score.
