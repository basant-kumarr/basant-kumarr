Fraud Detection

Machine Learning

Built an XGBoost model to detect fraudulent transactions on a public credit card dataset, with SMOTE for the class imbalance and SHAP so every flag can be explained.

99.9% AUC-ROC · 97.2% precision

PythonXGBoostSHAPMachine Learning

In testing it detected 437 more fraud cases than the logistic regression baseline.

Public dataset, not proprietary card network data. It is cleaner and more separable than real transactions, so the ceiling is higher than production would allow. The useful part is explainability, not the score.
