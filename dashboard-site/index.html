Featured project · Machine learning

Fraud Detection

Machine Learning

Built an XGBoost model to detect fraudulent transactions on a public credit card dataset, with SMOTE for the heavy class imbalance and SHAP so every flag can be traced to the features behind it.

  • 99.9%AUC-ROC
  • 97.2%Precision
  • +437Fraud cases caught vs baseline
  • SHAPExplainable AI

Public dataset, not proprietary card network data. It is cleaner and more separable than real transactions, so the useful part is explainability, not the score. Baseline: logistic regression.
